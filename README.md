# Tip Calculator

A user-friendly web application to calculate tips and split bills among people. Designed for simplicity and efficiency with a clean and responsive interface.

## Features
- Input bill amount, select tip percentage, and specify the number of people.
- Option to choose predefined tip percentages or set a custom percentage.
- Calculates total tip, total amount, tip per person, and total per person.
- Responsive design for all screen sizes.

## Technologies Used
- **HTML**: For the structure of the app.
- **CSS**: For styling and layout.
- **JavaScript**: For dynamic functionality and calculations.

## How to Use
1. Enter the bill amount in ₹.
2. Select a tip percentage or enter a custom percentage.
3. Specify the number of people to split the bill.
4. Click "Calculate" to view the detailed breakdown.
